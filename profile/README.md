# 乙构智能

### YIGO AI

**让企业更智能，让个人更高效。** · **少做重复，多做创造。**

乙构智能聚焦 AI Agent、自动化、企业智能化与系统集成，让 AI 能力接入 ERP、协同平台、数据和真实业务流程，帮助企业重构工作流与人机协作方式。

## 我们做什么 · What We Do

- **AI Agent 与 AI 员工**：围绕明确的业务目标设计任务、工具和人工确认边界。
- **流程自动化**：减少重复操作，让流程可追踪、可验证、可持续维护。
- **企业系统集成**：连接 ERP、办公协同、数据服务与现有业务系统。
- **跨平台工具**：为桌面与移动工作流构建实用的自动化能力。

## 工作方法 · How We Work

真实问题 → 流程梳理 → 自动化与 AI 设计 → 验证交付 → 持续优化

先理解业务约束和数据流，再决定由程序、AI 或人工处理，并以可核验的结果持续改进。

## 工程理念

> 程序负责确定性数据流，AI 处理非确定性判断，关键风险由人确认。

我们重视真实场景、清晰边界、可维护实现和持续迭代。
